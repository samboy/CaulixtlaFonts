# What this is

This is KilroyCweb with the following hinted:

- TTFautoHint is run on just the non-bold, non-italic font, and the
  files are edited to only have the numbers hinted
- The Bold and Italic fonts are unhinted

JustNumbers.txt: Just the numbers with full TTFautohint instructions

KilroyCweb-regular.sfd: Only numbers have TTFautohint instructions

KilroyCweb-regular.ttf: Only numbers have TTFautohint instructions

NoTTinstrs.sfd: Only global TTF autohint instructions, no per-glyph insts
