# WOFF

This format is supported by modern web browsers, and is also supported
by Internet Explorer 9-11. The reason to use WOFF2 instead is because
WOFF2 is smaller, and is also supported by modern web browsers.

# EOT

There is no reason to have this format here in 2025, but for the sake
of completeness I have included it. 

EOT is a proprietary font format Microsoft used in Internet Explorer 6-8;
while IE never ended up supporting WOFF2, IE9-11 have WOFF support.
