These are renderings of VenusTerm so that `xterm` can be usable on my
160dpi Thinkpad T14s computer.

The file `INSTALL.txt` has the incantations needed to convert and install
these fonts in Ubuntu 26.04 once `xterm` and some X fonts are installed.
These incantations are for the larger 33px font, but they also work with 
the smaller 29px font.

The file `VenusTerm.sfd` is the FontForge source, and it has both the
vector font as well as the raster fonts.

VenusTerm.sfd is OFL licensed, with the reserved name “Fira”.  The
other files here are public domain; in the US, one cannot copyright a
bitmap rendering of a vector font.
