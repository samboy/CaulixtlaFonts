The Caulixtla Font set

This is a set of six different fonts (three type faces) which I use on my personal webpage:
  • Serif regular
  • Serif italic
  • Serif bold
  • Sans semi-bold
  • Sans semi-bold Small Caps
  • Monospace
In order to minimum page load times, the fonts have been subsetted to have only symbols in English and Spanish. Here is how the primary fonts (Serif regular, Serif italic, and Sans semi-bold) are subsetted:

The fonts have been converted in to all modern web font formats: WOFF, WOFF2, the short-lived and obsolete SVG font format, and even the now-obsolete EOT used in first-2000s-decade versions of Internet Explorer. In addition, the Fontforge .sfd source files are available for the primary fonts (Again: Serif regular, Serif italic, and Sans semi-bold).

Files can be viewed at the GitHub repo. There’s also a sample of how text looks rendered with the primary fonts.

The fonts are open source, as described in COPYING.TXT.

Kilroy

Kilroy is my version of Robot Serif which is the new font I am using in the 2020s. The font has a more distinct style which invokes the typewriters of the mid-20th century in a porportional font, and is a serif modern replacement which fills the same rold Verdana filled in the 1990s and first 2000s decade: A very readable screen font. Unlike Verdana, the font is OFL licensed and is a fully variable font.

Even on low resolution displays, Kilroy (Roboto Serif) looks very nice and, unlike Verdana, doesn’t need extensive hinting to be a very friendly and readable screen font, even on old 75dpi displays.
